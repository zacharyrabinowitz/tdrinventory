Unit Details

New Inventory Mode

Simple Count is one flat number, edited directly — best for items you never receive in lots (e.g. cans/bottles you count by hand). Lot Tracking receives dated boxes/cases that flow through the Stages below, land in a Storage Location, and can be reconciled.
e.g. a case of beer needs no prep — it's sellable the moment it's received. Raw wings do — they get cooked/portioned first. Pick one to set up Reconcile Style and Stages below, then adjust as needed.
Pick individual units if stock gets prepped/portioned before it's sellable (e.g. raw wings → cooked wings). Pick raw box/case if what you receive is what you sell, no prep step (e.g. cases of beer or liquor).

Stages — the order stock moves through, e.g. Raw → Prepped

Most box/case items only need one stage — mark it Sellable and you're done (a case of beer isn't "prepped," it's just received and sellable). Only add more stages if items actually go through a preparation step first. Use the arrows to set the order; mark exactly one stage Sellable — that's the stage counted as "available" everywhere (Item Hub, Order page, reports).

Storage Locations

e.g. Freezer / Cooler / Out. Mark exactly one location On-Hand — that's where the Sellable stage's units are counted from as "in stock."
